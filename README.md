## 2. 🗺️ The Database, Positioning, and Target Navigation Architecture

Most apps fold the second things get heavy. PROXAID doesn't blink:

Runs heavy and self-contained on laptops and phones alike, zero network needed.
* **Pinpoint GPS & Inverse Triangulation Logic:** Your hardware GPS grabs your coordinates instantly. If GPS and cell towers completely flatline, the system falls back to your last saved drop or calculates your sector using local cell tower metadata zones (e.g., Zala region / Nagykanizsa grid).

Just type what you need raw into the search box (e.g., *"Szepetnek pharmacy"* or *"Nagykanizsa"*), and the local smart algorithm spits out the closest regional node right away. If you're searching for something outside the local cache while you've still got a blip of net, it pulls it live from real-world open data (OpenStreetMap), pins it, and **permanently caches it to your memory** for the next time you go offline.
